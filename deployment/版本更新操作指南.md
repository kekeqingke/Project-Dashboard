# ZWY项目管理系统 - 版本更新操作指南

## 📋 更新流程概述

当你在开发环境完成新功能开发后，需要将更新部署到服务器时，按以下步骤操作：

---

## 🔄 日常版本更新步骤

### 步骤1：准备更新文件
**⚠️ 重要：只拷贝代码文件，不要覆盖数据文件**

#### ✅ 需要拷贝的文件/目录：
```
从开发环境拷贝到服务器 D:\web_zwy\：
├── frontend/                    (整个前端目录)
├── backend/
│   ├── *.py                    (所有Python文件)
│   └── requirements.txt        (依赖文件)
└── deployment/                 (部署脚本目录)
```

#### ❌ 不要覆盖的数据文件：
```
服务器上保留这些文件：
├── backend/
│   ├── .env                    (配置文件 - 包含密码等)
│   ├── *.db                    (数据库文件 - 包含所有数据)
│   └── uploads/                (上传文件目录)
```

### 步骤2：运行更新脚本
1. 在服务器上打开命令行（管理员身份）
2. 切换到项目目录：
   ```batch
   cd /d "D:\web_zwy"
   ```
3. 运行更新脚本：
   ```batch
   deployment\update_deploy.bat
   ```

### 步骤3：重启服务
1. **停止现有后端服务**（如果正在运行）：
   - 在后端服务窗口按 `Ctrl+C`

2. **启动后端服务**：
   ```batch
   deployment\start_backend.bat
   ```

3. **确认Nginx正常运行**：
   - 如未运行：`deployment\start_nginx.bat`

4. **验证更新**：
   - 访问：http://10.13.33.52
   - 检查新功能是否正常

## 🛠️ 详细操作说明

### 选择性文件拷贝方法

#### 方法1：手动选择拷贝
1. 打开开发环境项目文件夹：`F:\pinrui\web_zwy\`
2. 分别选择并拷贝：
   - `frontend` 文件夹 → 服务器 `D:\web_zwy\frontend`
   - `backend` 文件夹中的 `.py` 文件 → 服务器 `D:\web_zwy\backend\`
   - `backend\requirements.txt` → 服务器 `D:\web_zwy\backend\`
   - `deployment` 文件夹 → 服务器 `D:\web_zwy\deployment`

#### 方法2：使用批处理同步（推荐）
创建一个同步脚本，只拷贝代码文件：

```batch
@echo off
echo 正在同步代码文件到服务器...

:: 同步前端
xcopy "F:\pinrui\web_zwy\frontend" "D:\web_zwy\frontend\" /E /Y

:: 同步后端Python文件
xcopy "F:\pinrui\web_zwy\backend\*.py" "D:\web_zwy\backend\" /Y
xcopy "F:\pinrui\web_zwy\backend\requirements.txt" "D:\web_zwy\backend\" /Y

:: 同步部署脚本
xcopy "F:\pinrui\web_zwy\deployment" "D:\web_zwy\deployment\" /E /Y

echo 代码同步完成！
pause
```

## 🔍 更新脚本功能说明

`update_deploy.bat` 脚本会自动完成：

1. **数据备份**：
   - 备份数据库文件（*.db）
   - 备份配置文件（.env）
   - 备份上传文件（uploads/）

2. **代码更新**：
   - 重新构建前端（npm run build）
   - 更新静态文件到后端
   - 安装/更新后端依赖

3. **数据恢复**：
   - 恢复原有数据库
   - 恢复原有配置
   - 恢复原有上传文件

## ⚠️ 注意事项

### 更新前检查：
- [ ] 确认开发环境功能正常
- [ ] 确认要更新的文件已保存
- [ ] 服务器上有足够磁盘空间

### 更新时注意：
- [ ] 不要中断更新脚本运行
- [ ] 如有错误立即停止并检查
- [ ] 保持网络连接稳定

### 更新后验证：
- [ ] 检查前端界面是否正常
- [ ] 测试新功能是否工作
- [ ] 验证原有数据是否完整
- [ ] 检查用户登录是否正常

---

## 🆘 故障排除

### 如果更新失败：
1. **查看错误信息**：仔细阅读脚本输出的错误
2. **恢复备份**：从 `deployment\backup` 目录恢复
3. **重新尝试**：修复问题后重新运行更新脚本

### 常见问题：
- **前端构建失败**：检查Node.js版本，重新运行 `npm install`
- **依赖安装失败**：检查网络连接，确认Python环境
- **静态文件更新失败**：检查磁盘空间，确认目录权限

### 紧急回滚：
如果更新后系统异常，可以：
1. 停止所有服务
2. 从备份恢复数据文件
3. 使用上一个版本的代码文件
4. 重新启动服务
