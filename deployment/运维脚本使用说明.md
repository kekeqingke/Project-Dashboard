# ZWY项目管理系统 - 运维脚本使用说明

## 📋 脚本概览

| 脚本文件 | 功能描述 | 使用场景 |
|---------|---------|----------|
| `scheduled_maintenance.bat` | 定时维护脚本 | 凌晨3点自动执行 |
| `setup_scheduled_task.bat` | 任务计划配置 | 设置定时任务 |
| `service_manager.bat` | 手动服务管理 | 日常运维操作 |

---

## 🚀 快速开始

### 1. 设置定时维护（推荐）

**第一步：配置定时任务**
```cmd
# 右键点击以下脚本，选择"以管理员身份运行"
setup_scheduled_task.bat
```

**第二步：验证配置**
- 任务将在每天凌晨3:00自动执行
- 可在"任务计划程序"中查看任务状态

**第三步：测试运行**
```cmd
# 手动执行一次维护脚本进行测试
scheduled_maintenance.bat
```

### 2. 日常手动维护

**交互模式**：双击 `service_manager.bat`

**命令行模式**：
```cmd
service_manager.bat status      # 查看服务状态
service_manager.bat restart     # 重启所有服务  
service_manager.bat backup      # 仅备份数据
service_manager.bat maintenance # 完整维护
```

## 🛠️ 功能详解

### 定时维护功能

**执行流程：**
1. ✅ 检查服务状态
2. ✅ 优雅停止服务（Nginx → 后端）
3. ✅ 备份数据库和配置文件
4. ✅ 清理过期文件（备份保留30天，日志保留7天）
5. ✅ 重新启动服务
6. ✅ 执行健康检查
7. ✅ 生成维护报告

**自动备份内容：**
- 数据库文件：`backend/zwy_project.db`
- 环境配置：`backend/.env`
- Nginx配置：`D:/nginx-1.28.0/conf/nginx.conf`

### 服务管理功能

**状态检查：**
- 后端API服务（端口8000）
- Nginx Web服务（端口80）
- 网站可访问性测试

**服务控制：**
- 启动/停止/重启所有服务
- 进程ID识别和安全停止
- 服务启动验证

## 🕐 定时任务管理

### 查看任务状态
```cmd
schtasks /query /tn "ZWY项目定时维护"
```

### 立即执行任务
```cmd  
schtasks /run /tn "ZWY项目定时维护"
```

### 修改执行时间
```cmd
# 改为凌晨2点执行
schtasks /change /tn "ZWY项目定时维护" /st 02:00

# 改为每周日凌晨3点执行  
schtasks /change /tn "ZWY项目定时维护" /sc weekly /d SUN
```

### 启用/停用任务
```cmd
schtasks /change /tn "ZWY项目定时维护" /enable   # 启用
schtasks /change /tn "ZWY项目定时维护" /disable  # 停用
```

### 删除任务
```cmd
schtasks /delete /tn "ZWY项目定时维护" /f
```

## 🚨 故障排除

### 常见问题

**问题1：定时任务未执行**
- 检查任务计划程序服务是否启动
- 确认脚本路径正确且可访问
- 检查系统账户权限

**问题2：服务启动失败**
- 检查端口占用：`netstat -ano | findstr :8000`
- 查看错误日志：`maintenance_logs\最新日志文件`
- 手动测试服务启动

**问题3：备份失败**
- 检查磁盘空间
- 确认文件权限
- 验证源文件存在

### 手动恢复步骤

**如果维护后服务异常：**

1. 停止所有服务
```cmd
service_manager.bat stop
```

2. 从备份恢复数据库
```cmd
copy "backups\最新备份\zwy_project_*.db" "backend\zwy_project.db"
```

3. 重新启动服务
```cmd  
service_manager.bat start
```

## ⚠️ 重要注意事项

### 维护时间窗口
- **默认时间**：每天凌晨3:00-3:05
- **服务中断**：约1-2分钟
- **建议时间**：用户访问量最少时段

### 数据安全
- 备份文件自动保留30天
- 建议定期将备份复制到其他位置
- 维护前会自动停止服务确保数据一致性

### 权限要求
- 定时任务需要管理员权限设置
- 维护脚本需要访问系统进程权限
- 确保防火墙不会阻止脚本执行

### 监控建议
- 定期查看维护日志确认执行状态
- 监控备份目录大小避免磁盘空间不足
- 在维护时间后验证系统正常运行

4. **应急处理**：使用 `service_manager.bat` 手动恢复服务
